## Meaning of statuses

- **ACCEPTED** — accepted by the project owner.
- **NORMATIVE-DRAFT** — candidate normative requirement.
- **HYPOTHESIS** is a testable technical hypothesis.
- **TARGET** — target metric that has not yet been achieved.
- **RESEARCH** - research extension.
- **SUPERSEDED** - replaced solution.

## Update rule

Every meaningful decision from conversation must be recorded in the decision
log and relevant thematic document before the current work cycle is complete.
